# Chat-Application-using-Python
Chat Application (Python, Tkinter, Socket Programming, Multithreading)

Developed a real-time chat application with both client and server modules using Python.

Implemented socket programming for reliable communication between client and server.

Designed a GUI interface with Tkinter to enhance user experience, including message display, input field, and send button.

Integrated multithreading to handle simultaneous sending and receiving of messages without freezing the UI.

Built features such as:

Client-side message sending and receiving

Server-side connection handling and continuous listening

Error handling for disconnections and failed connections
